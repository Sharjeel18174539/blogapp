## Getting Started

This project is a starting point for a Flutter application.

In this Application, we will learn about Clean Architecture in Flutter
by building a full stack application. We will learn about SOLID Principles 
and its usage in Clean Architecture, Bloc & Cubit State Management, 
Supabase, get_it and the need for dependency injection.
